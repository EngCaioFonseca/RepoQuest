# RepoQuest

An open-source, local-first contribution RPG. Turn your real open-source work into character levels, ranks, titles, quests, and shareable achievements.

Working name; initial development is underway.

## Initial product

- Track a GitHub identity across selected repositories, initially oss-aspen/8Knot and chaoss/CollectOSS.
- Show contribution evidence, XP, levels, E–S ranks, three specialization tracks, quests, and achievements.
- Provide a clearly labelled fixture-driven demo with no credentials required.
- Import real GitHub contributions with a server-side token and explicit sync.
- Keep data locally in SQLite and export a shareable SVG character card.
- Run locally or with Docker Compose.

Original dark-fantasy/system-interface visual identity inspired by progression RPGs; no copied franchise assets.
